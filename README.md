# Shprotify

A self-hosted music server for your own collection. Share one library with
other accounts and listen from a separate player.

[![Docs][docs-badge]][docs]
![Rust][rust-badge]
[![License][license-badge]](LICENSE)

> [!IMPORTANT]
> **Work in progress (WIP).** Shprotify is still in development ahead of its first release.

## Features

- **Music library.** Scan local folders and browse or search by artist, album
  or track.
- **Playback.** Stream original audio with seeking, or save tracks for
  offline listening in a compatible player.
- **Personal collections.** Keep your own favorites, queue and listening
  history. Create private playlists or share them with other accounts.
- **Music discovery.** Find new music through recommendations, charts and
  public playlists. Optionally add selected tracks from YouTube with the
  experimental downloader.
- **Library management.** Review metadata from MusicBrainz and artwork from
  Cover Art Archive. Schedule scans to pick up new music.
- **Client API.** Build a player for the versioned HTTP API using OpenAPI
  and the built-in Swagger UI.
