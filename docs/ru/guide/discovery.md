# Поиск новой музыки

Начните с того, что уже слушаете. Shprotify может предложить треки из вашей
библиотеки, напомнить о забытом избранном или помочь найти музыку, которой
у вас ещё нет. Для каждой задачи можно создать свою ленту.

## Выберите ленту

| Что хочется найти | Какая лента подойдёт | Источник |
| --- | --- | --- |
| Что послушать по своим вкусам | Личная лента предлагает треки из вашей библиотеки. При включённых внешних источниках она может также предложить похожую музыку и публичные плейлисты. | Библиотека, при желании Last.fm и ListenBrainz |
| Что давно не слушали | «Послушать снова» возвращает треки из избранного, которые вы не дослушивали за последние 30 дней. | Библиотека |
| Чарты или подборку по жанру | Откройте общий чарт, чарт страны или ленту по тегу, например `jazz`. Можно также искать треки по названию или найти музыку, похожую на конкретный трек или исполнителя. | Last.fm |
| Готовую подборку | Найдите публичный плейлист по названию или описанию. Если уже знаете его ID, откройте плейлист сразу. | ListenBrainz |
| Новинки любимых исполнителей | Откройте ленту новых релизов. Shprotify ищет релизы исполнителей из вашего профиля, у которых подтверждён MusicBrainz ID. | MusicBrainz |

## Как подбираются рекомендации {#how-recommendations-work}

**Что нравится вам.** Личная лента учитывает лайки в библиотеке и в
рекомендациях, засчитанные прослушивания и исполнителей, за которыми вы
следите. Недавние прослушивания влияют сильнее старых, а короткий пропуск
сам по себе не считается дизлайком. Если истории пока мало, начните с
любимых исполнителей и тегов для внешнего поиска. У каждого пользователя
свои рекомендации и отметки, даже если библиотека общая.

**Где сервер ищет музыку.** Для начала достаточно своей коллекции.
Например, если вы часто слушаете одного исполнителя, лента может
предложить другую его запись из библиотеки. При включённом Last.fm
сервер ищет похожие треки и исполнителей, а также берёт подборки по тегам
и чарты. В ListenBrainz он может подобрать публичные плейлисты по тегу
или имени исполнителя. Новые релизы ищутся отдельной лентой в MusicBrainz,
по подтверждённым ID исполнителей. История прослушивания остаётся на вашем
сервере. Внешние сервисы получают поисковые запросы, например название
трека, имя исполнителя или тег.

**Почему находка может быть недоступна для прослушивания.** Shprotify
сверяет рекомендации с библиотекой. Если у находки есть MusicBrainz ID,
он ищет точное совпадение по нему. Без ID может подойти однозначное
совпадение названия и исполнителей. Если записи нет или у неё ещё нет
аудиофайла, отметьте «Хочу добавить» и вернитесь к ней позже.

## Подключите внешние источники

Внешние источники включает администратор сервера. Выберите нужные:

- **Last.fm.** Создайте ключ приложения. Он хранится в настройках сервера.
  [Получить ключ Last.fm](https://www.last.fm/api/account/create)
- **ListenBrainz.** Для поиска и чтения публичных плейлистов достаточно
  включить источник. [Документация ListenBrainz](https://listenbrainz.readthedocs.io/en/latest/users/api/playlist.html)
- **MusicBrainz.** Для новых релизов включите источник и подтвердите
  MusicBrainz ID нужных исполнителей в каталоге. [Как связать данные с MusicBrainz](./metadata.md)

В примере включены все три источника. Замените `you@example.org` своим
контактом. Чтобы оставить Last.fm выключенным, не задавайте ключ или
оставьте его пустым. ListenBrainz и MusicBrainz можно выключить значением
`false`.

::: code-group
```yaml [Compose]
# В блоке environment сервиса shprotify
SHPROTIFY_DISCOVERY__ENABLED: "true"
SHPROTIFY_DISCOVERY__USER_AGENT: "shprotify/0.1.0 (mailto:you@example.org)"
SHPROTIFY_DISCOVERY__LASTFM_API_KEY: "YOUR_APPLICATION_KEY"
SHPROTIFY_DISCOVERY__LISTENBRAINZ_ENABLED: "true"
SHPROTIFY_DISCOVERY__MUSICBRAINZ_ENABLED: "true"
```
```toml [TOML]
[discovery]
enabled = true
user_agent = "shprotify/0.1.0 (mailto:you@example.org)"
lastfm_api_key = "YOUR_APPLICATION_KEY"
listenbrainz_enabled = true
musicbrainz_enabled = true
```
:::

Если секция `[discovery]` уже есть, добавьте параметры в неё.
[Как применить настройки](./configuration.md)

## Создайте и обновите ленту

Если ваш клиент поддерживает рекомендации, выберите тип ленты,
укажите тег или исполнителя там, где это нужно, и дождитесь результатов.
Создание ленты запускает первый поиск. Позже ту же ленту можно обновить.

::: details Как создать личную ленту вручную в Swagger
Войдите под своим аккаунтом и нажмите **Authorize**, как в
[быстром старте](./quick-start.md#воидите). В разделе **Discovery**
выполните `POST /api/v1/me/discovery/feeds` с таким телом запроса:

```json
{"kind":"personal"}
```

В ответе будет `id` задания и `feed_id` ленты. Проверьте задание через
`GET /api/v1/me/discovery/jobs/{id}`. После статуса `completed` подставьте
`feed_id` в `GET /api/v1/me/discovery/feeds/{id}/items`. Для следующего
обновления той же ленты используйте `POST /api/v1/me/discovery/feeds/{id}/refresh`.
:::

## Что делать с находками

- **Послушать.** Если у найденной записи уже есть аудиофайл в вашей
  библиотеке, его можно открыть в плеере.
- **Отложить.** Отметьте «Хочу добавить». Находка останется в личном списке
  после обновления ленты. Если на сервере включена загрузка, можно отдельно
  поискать аудио для найденного трека. [Загрузка с YouTube](./downloads.md)
- **Скрыть.** Уберите неподходящую рекомендацию из своей выдачи.
- **Собрать плейлист.** Экспорт ленты создаёт обычный личный плейлист из
  подходящих записей вашей библиотеки. Следующие обновления ленты
  этот плейлист не меняют.

> [!NOTE]
> Во внешней ленте могут быть треки, альбомы и целые плейлисты. Ссылка
> источника ведёт на страницу с музыкой. Для воспроизведения через
> Shprotify нужен аудиофайл в вашей библиотеке.

## Если лента не обновилась

По умолчанию между обновлениями одного аккаунта проходит не меньше
60 секунд. Ответы внешних сервисов могут использоваться повторно
в течение часа, поэтому сразу после обновления выдача может быть прежней.

Если источник не ответил, попробуйте обновить ленту позже. При неудачном
обновлении ленты её прежние результаты сохраняются. Если лента новых
релизов пуста, проверьте, что у исполнителей из вашего профиля
подтверждён MusicBrainz ID.

Для регулярных обновлений настройте [расписание ленты](./automation.md).
Если пишете клиент, см. [руководство по рекомендациям и загрузкам](../clients/discovery.md).
