# Теги образов и команды Docker

Имя контейнерного образа: `ghcr.io/mois3y/shprotify`.

| Тег | Для чего |
| --- | --- |
| `latest` | Использовать последний опубликованный релиз |
| `0.1.0` | Оставаться на выбранной версии до явного обновления |

Берите точный тег со страницы релиза. Скачать образ можно только после
его публикации. Ответы `manifest unknown` и `denied` относятся
к доступности образа в registry, а не к настройкам приложения.

## Закрепите версию в Compose

[Пример установки](./quick-start.md) использует `latest`.
Для выбора релиза создайте `.env` рядом с `compose.yaml`:

```dotenv
SHPROTIFY_IMAGE=ghcr.io/mois3y/shprotify:0.1.0
```

Переменную читает Compose для выбора образа. Это не настройка Shprotify,
передавать её внутрь контейнера не нужно.

## Запуск без Compose

Создайте `data` и `music` и отдайте `data` пользователю/группе 1000,
как в руководстве по установке. Из этой директории выполните:

```sh
docker run -d --name shprotify --restart unless-stopped \
  --stop-timeout 90 \
  -p 127.0.0.1:3000:3000 \
  -v "$PWD/data:/data" \
  -v "$PWD/music:/music:ro" \
  -e SHPROTIFY_HTTP__BIND=0.0.0.0:3000 \
  -e SHPROTIFY_DATABASE__PATH=/data/shprotify.db \
  -e 'SHPROTIFY_LIBRARY__DIRECTORIES=["/music"]' \
  -e SHPROTIFY_LIBRARY__PUBLIC_CATALOG=false \
  -e SHPROTIFY_DOCS__ENABLED=true \
  ghcr.io/mois3y/shprotify:latest
```

Команды аккаунтов вызываются через
`docker exec -it shprotify shprotify user ...`.
Полные примеры есть в разделе [Пользователи](./accounts.md).

## Адрес хоста и адрес контейнера

`127.0.0.1:3000:3000` публикует порт только на loopback Docker-хоста.
`0.0.0.0:3000` в `SHPROTIFY_HTTP__BIND` задаёт адрес **внутри**
контейнера. Это разные настройки.

Для доступа из доверенной локальной сети можно указать `3000:3000`.
Для доступа через интернет настройте [HTTPS](./proxy.md).

## Обновления

Следуйте разделу [Резервные копии и обновления](./operations.md).
Скачивание образа не заменяет работающий контейнер до его пересоздания.
Не включайте автоматические обновления, если хотите сами выбирать момент
применения миграций базы.

Самостоятельная сборка образа описана в [руководстве Nix](./nix.md).
