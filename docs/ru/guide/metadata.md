# Теги и обложки

Если название альбома отображается неверно или у трека нет обложки,
администратор может поправить это в каталоге Shprotify. Начните с того
источника, который подходит для вашей задачи.

## Откуда берутся данные

| Источник | Что можно получить |
| --- | --- |
| Теги ваших аудиофайлов | При сканировании Shprotify читает название, исполнителя, альбом и номера трека и диска. Если картинка уже встроена в файл, её можно извлечь отдельным действием. |
| [MusicBrainz](https://musicbrainz.org/doc/MusicBrainz_API) | Позволяет найти исполнителя, конкретное издание альбома или запись по названию либо точному идентификатору MusicBrainz (MBID). |
| [Cover Art Archive](https://musicbrainz.org/doc/Cover_Art_Archive/API) | Предлагает переднюю обложку конкретного издания альбома, когда оно уже связано с MusicBrainz. |
| [AcoustID](https://acoustid.org/webservice) | Помогает опознать запись по звучанию, когда название неизвестно или теги перепутаны. |
| Ваши правки | Можно исправить название и исполнителей в каталоге или загрузить свою картинку. |

Правки остаются в каталоге. Теги и картинка внутри исходного аудиофайла
сохраняются как были. Чтобы вручную исправить данные, загрузить картинку
или извлечь её из файла, подключать внешний поиск не требуется.

## Включите поиск в MusicBrainz

Замените `you@example.org` своим контактным адресом. Shprotify передаёт
его в заголовке `User-Agent`, чтобы оператор MusicBrainz мог связаться
с вами при проблемах с запросами. Для поиска ключ API не нужен.

::: code-group
```yaml [Compose]
# В блоке environment сервиса shprotify
SHPROTIFY_METADATA__ENABLED: "true"
SHPROTIFY_METADATA__USER_AGENT: "shprotify/0.1.0 (mailto:you@example.org)"
```
```toml [TOML]
[metadata]
enabled = true
user_agent = "shprotify/0.1.0 (mailto:you@example.org)"
```
:::

Если секция `[metadata]` уже есть, добавьте параметры в неё.
[Как применить настройки](./configuration.md)

> [!NOTE]
> Эти параметры включают поиск данных и обложек. Last.fm и другие
> источники рекомендаций настраиваются отдельно. [Поиск новой музыки](./discovery.md)

## Найдите и проверьте совпадение

Если ваш клиент умеет управлять метаданными, выберите в нём исполнителя,
альбом или трек и запустите поиск. Сравните название и исполнителей,
а для альбома ещё и издание. Подтвердите совпадение и укажите, какие
данные перенести. Можно связать альбом с MusicBrainz и оставить его
название и исполнителей как есть.

::: details Пример ручного поиска альбома через Swagger
[Войдите администратором](./quick-start.md#воидите). В разделе **Releases**
найдите нужный альбом через `GET /api/v1/releases` и возьмите его `id`.
Дальнейшие операции поиска находятся в **Admin: Enrichment**.

1. Выполните `POST /api/v1/metadata/{kind}/{id}/jobs` с `kind=release`
   и ID альбома. В теле запроса укажите `{"action":"search"}`, чтобы
   искать по текущему названию.
2. Скопируйте ID задания и откройте `GET /api/v1/metadata/jobs/{id}`.
   После завершения предложения появятся в списке `candidates`.
3. Выберите совпадение. Узнайте текущую `version` альбома через
   `GET /api/v1/metadata/release/{id}` в разделе **Admin: Metadata**.
   Затем выполните `POST /api/v1/metadata/candidates/{id}`, подставив
   ID предложения. В примере ниже замените `1` полученной версией.

   ```json
   {"version":1,"name":false,"credits":false}
   ```

С этим запросом вы подтвердите MBID и сохраните своё название и список
исполнителей. Если альбом уже изменился, получите свежую версию и ещё
раз проверьте предложение перед применением.
:::

Поиск, в том числе [по расписанию](./automation.md), создаёт предложения.
Каталог меняется только после вашего подтверждения.

## Добавьте обложку

- **Из аудиофайла.** Выберите трек или альбом и связанный с ним файл.
  Запустите извлечение встроенной картинки (`embedded_artwork`). Если в
  тегах помечена передняя обложка, Shprotify предложит её.
- **Из Cover Art Archive.** Сначала подтвердите MBID нужного издания
  альбома. Затем запустите поиск обложки (`cover_art`). Если у издания
  есть передняя обложка, Shprotify предложит её на проверку.
- **С компьютера.** Загрузите свою картинку для исполнителя, альбома или
  трека через клиент с управлением обложками либо через
  `PUT /api/v1/metadata/{kind}/{id}/artwork` в **Admin: Metadata**.

Предложенную картинку можно посмотреть перед применением.
Принимаются JPEG и PNG до 5 МиБ и до 4096 пикселей по каждой стороне.
Сохранённые картинки лежат в `shprotify.db`.

## Опознайте трек по звучанию (AcoustID)

Если поиск по названию не помог, попробуйте аудиоотпечаток. Утилита
`fpcalc` уже есть в Docker-образе. Она вычисляет отпечаток на сервере,
а Shprotify отправляет его и длительность трека в AcoustID. Аудиофайл
остаётся у вас. Найденные совпадения сервер уточняет в MusicBrainz.

Включите внешний поиск, как показано выше, и добавьте ключ,
полученный после регистрации приложения в AcoustID.
Для этого нужен ключ приложения, а не личный ключ для отправки отпечатков.
[Документация AcoustID](https://acoustid.org/webservice)

::: code-group
```yaml [Compose]
# В блоке environment сервиса shprotify
SHPROTIFY_METADATA__ACOUSTID_KEY: "YOUR_APPLICATION_KEY"
SHPROTIFY_METADATA__FPCALC_PATH: "fpcalc"
```
```toml [TOML]
[metadata]
acoustid_key = "YOUR_APPLICATION_KEY"
fpcalc_path = "fpcalc"
```
:::

Выберите запись и её аудиофайл, затем запустите поиск по отпечатку
(`fingerprint`). Проверьте совпадение перед применением, как при обычном
поиске. Пустой `fpcalc_path` отключает поиск по отпечатку.
