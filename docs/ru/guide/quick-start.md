# Быстрый старт с Docker

Запустим Shprotify, создадим администратора и добавим первые треки
в библиотеку. Понадобятся Docker с Compose и несколько аудиофайлов.
Команды Docker выполняйте на компьютере, где будет работать сервер.

## 1. Подготовьте папки

```sh
mkdir -p shprotify/data shprotify/music
cd shprotify
```

Положите несколько треков в `music/`. В папке `data/` Shprotify будет
хранить базу и файлы, которые добавит сам, например загрузки с YouTube.

На Linux дайте пользователю контейнера право записи в `data/`:

```sh
sudo chown 1000:1000 data
sudo chmod 750 data
```

## 2. Создайте файл Compose

В папке `shprotify/` рядом с `data/` и `music/` сохраните
файл `compose.yaml`:

<<< ../../public/examples/compose.yaml{yaml}

> [!TIP]
> Если коллекция уже лежит в другой папке, укажите её путь вместо
> `./music` в строке `./music:/music:ro`. Пользователю контейнера
> с UID 1000 нужен доступ на чтение. Суффикс `:ro` защищает исходные
> файлы от изменений со стороны контейнера.

## 3. Запустите и проверьте сервер

```sh
docker compose pull
docker compose up -d
curl http://localhost:3000/api/v1/health
```

Как только сервер запустится, он ответит:

```json
{"status":"ok"}
```

Если ответа нет, подождите несколько секунд и повторите запрос.
Если сервер так и не ответил, посмотрите журнал:

```sh
docker compose logs --tail 50 shprotify
```

::: details Как открыть сервер с другого компьютера
Пример открывает порт только на самом сервере. Чтобы пройти настройку
с другого компьютера, выполните на нём команду ниже. Замените
`user@your-server` своим именем и адресом для SSH.

```sh
ssh -N -L 3000:127.0.0.1:3000 user@your-server
```

Пока туннель открыт, адреса с `localhost:3000` будут работать и на вашем
компьютере. Для постоянного доступа можно настроить
[HTTPS с Traefik](./proxy.md).
:::

## 4. Создайте администратора

Замените `alice` своим именем во всех трёх командах. Они создают
пользователя, дают ему права администратора и задают пароль.

```sh
docker compose exec shprotify shprotify user create --name alice
docker compose exec shprotify shprotify user role --name alice --role admin
docker compose exec shprotify shprotify user password --name alice
```

Последняя команда попросит ввести пароль дважды. Символы при вводе
в терминале не отображаются.

> [!NOTE]
> При создании пользователя в терминале один раз появится API-ключ.
> Храните его как пароль. Для входа на следующем шаге понадобятся
> имя пользователя и заданный пароль.

## 5. Добавьте музыку в библиотеку

Откройте <a href="http://localhost:3000/docs" target="_blank" rel="noreferrer">Swagger</a> в браузере.
Ниже показано, как вручную запустить сканирование и посмотреть результат.
Если ваш клиент умеет управлять библиотекой, всё это можно сделать в нём.

### Войдите

1. Откройте **Authentication** → `POST /api/v1/auth/login`.
2. Нажмите **Try it out**. В поле запроса вставьте JSON, подставьте своё имя
   и пароль, затем нажмите **Execute**.

   ```json
   {
     "name": "alice",
     "password": "ваш-пароль"
   }
   ```

3. Скопируйте значение `access_token` из ответа. Нажмите **Authorize**
   вверху страницы, вставьте токен и подтвердите.

### Запустите сканирование

1. В разделе **Admin: Library** откройте `POST /api/v1/library/scans`
   и нажмите **Try it out** → **Execute**. Скопируйте число из поля `id`.
2. В том же разделе откройте `GET /api/v1/library/scans/{id}`, подставьте
   это число и выполните запрос. Если сканирование ещё идёт, повторите
   запрос через несколько секунд. Статус `completed` означает, что оно
   завершилось.
3. Откройте **Recordings** → `GET /api/v1/recordings` и выполните запрос.
   Добавленные записи появятся в списке `items`.

Если список пуст или в отчёте есть ошибки, проверьте путь к папке,
права на чтение и [отчёт сканирования](./library.md#импорт-папки).
