# Загрузка с YouTube

Если нужного трека ещё нет в библиотеке, Shprotify может поискать его
на YouTube. Вы выбираете видео, а сервер сохраняет из него аудио и добавляет
его в общую библиотеку. Функцию включает администратор. После этого
пользоваться ей могут и обычные участники.

> [!NOTE]
> Загрузка с YouTube экспериментальная. Если YouTube меняет работу поиска
> или выдачу аудио, отдельные загрузки могут перестать работать.
> Музыку из библиотеки по-прежнему можно слушать. [О музыке и правах](./introduction.md)

## Включите загрузки

Включите загрузки и сам источник YouTube. Пример использует папку
`/data/downloads` внутри контейнера. В установке из быстрого старта она
находится на хосте в `./data/downloads/`.

::: code-group
```yaml [Compose]
# В блоке environment сервиса shprotify
SHPROTIFY_DOWNLOADS__ENABLED: "true"
SHPROTIFY_DOWNLOADS__YOUTUBE__ENABLED: "true"
SHPROTIFY_DOWNLOADS__DIRECTORY: "/data/downloads"
```
```toml [TOML]
[downloads]
enabled = true
directory = "/data/downloads"

[downloads.youtube]
enabled = true
```
:::

Если эти секции или ключи уже есть, измените их на месте. Загрузчик
`yt-dlp`, FFmpeg и Deno уже входят в Docker-образ.
[Как применить настройки](./configuration.md)

> [!TIP]
> Сохраняйте загрузки отдельно от папок, которые сканирует Shprotify.
> Сервер сам добавит скачанный трек в каталог. Если папки для загрузок
> ещё нет, Shprotify создаст её, когда сможет писать в родительскую папку.

## Найдите и загрузите трек

Если ваш клиент поддерживает загрузки, начните с трека из
[рекомендаций](./discovery.md) или записи в каталоге. Можно также искать
по названию и исполнителю.

1. Запустите поиск на YouTube. Сравните название видео, канал и длительность.
   Так проще выбрать оригинал, студийную запись или нужную версию.
2. Выберите один результат и подтвердите загрузку. Shprotify скачает аудио,
   проверит файл и добавит его в библиотеку.
3. После завершения откройте трек в обычном каталоге. Повторное
   сканирование для этого не требуется.

Историю поиска и ход загрузки видит только тот, кто её запустил.
Готовый трек доступен всем пользователям сервера. Для альбома или
плейлиста из рекомендаций выберите отдельный трек и найдите его
по названию и исполнителю.

::: details Как вручную загрузить один трек через Swagger
[Войдите под своим аккаунтом](./quick-start.md#воидите) и откройте раздел
**Downloads**. В этом примере поиск начинается с названия и исполнителя.

1. Выполните `POST /api/v1/me/downloads/searches` с телом запроса ниже.
   Замените название и исполнителя на свои.

   ```json
   {"kind":"query","title":"Название трека","artists":["Исполнитель"]}
   ```

2. Скопируйте `id` задания из ответа. Запрашивайте
   `GET /api/v1/me/downloads/{id}` с этим ID. Когда статус станет
   `completed`, получите варианты через `GET /api/v1/me/downloads/{id}/sources`.
3. Выберите результат и возьмите его `id`. Выполните
   `POST /api/v1/me/downloads`, заменив `17` на ID выбранного результата.

   ```json
   {"source_id":17}
   ```

4. Проверьте новое задание через `GET /api/v1/me/downloads/{id}`. После
   завершения `recording_id` укажет на запись в общей библиотеке.
:::

## Где лежит готовый файл

Сервер хранит готовые файлы в `./data/downloads/objects/`. В `.staging/`
внутри папки загрузок лежат временные файлы задания. Отменяйте загрузку
через клиент, пока она не перешла к импорту в библиотеку.

Формат зависит от найденного аудио. Можно получить, например, Opus или
AAC. Для прослушивания плеер должен поддерживать формат готового файла.

## Если загрузка не удалась

| Что случилось | Что попробовать |
| --- | --- |
| Загрузка недоступна в клиенте | Проверьте, включены ли оба переключателя и применились ли настройки сервера. Клиент тоже должен поддерживать загрузки. |
| Поиск ничего не нашёл или видео больше недоступно | Уточните название и исполнителя, запустите свежий поиск и выберите другой результат. |
| Сервер не принимает ещё одно задание | Дождитесь окончания активной загрузки и повторите попытку. |
| Загрузка прервалась или файл не прошёл проверку | Посмотрите сообщение задания. Проверьте свободное место и лимиты. Если поиск и загрузка перестали работать сразу для разных треков, проверьте, нет ли обновления образа. |

По умолчанию на весь сервер одновременно работают до двух заданий
поиска или загрузки. Один пользователь может поставить в очередь до трёх
заданий с учётом тех, что уже выполняются. Лимит на файл составляет
256 МиБ, на длительность аудио отводится до 30 минут, а на скачивание
до 10 минут. [Все настройки лимитов](./configuration.md#полный-справочник)

Чтобы остановить новые загрузки, задайте `downloads.youtube.enabled = false`
в TOML или `SHPROTIFY_DOWNLOADS__YOUTUBE__ENABLED: "false"` в Compose.
Оставьте папку загрузок в настройках, чтобы ранее добавленные треки
оставались доступными. Место на диске зависит от общего объёма коллекции.

Если вы пишете клиент, см. [руководство по рекомендациям и загрузкам](../clients/discovery.md).
