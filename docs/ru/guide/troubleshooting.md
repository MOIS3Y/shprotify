# Решение проблем

Начните с проверки, что контейнер работает и сервер отвечает. Выполняйте
команды из папки с `compose.yaml`:

```sh
docker compose ps -a shprotify
docker compose logs --tail 100 shprotify
curl -fsS http://localhost:3000/api/v1/health
```

Если используете Traefik, проверяйте свой HTTPS-адрес. Ответ
`{"status":"ok"}` означает, что сервер отвечает. Если проблема осталась,
выберите ниже подходящий случай.

## Сервер не запускается или не отвечает

| Что видно | Что проверить |
| --- | --- |
| Образ не скачивается | Проверьте имя и тег образа, доступ к реестру и опубликован ли этот тег. [Теги образов](./deployment.md) |
| `Permission denied` для базы или загрузок | Проверьте владельца и права на папку, подключённую как `/data`. Контейнер работает с UID/GID 1000. [Настройки и файлы](./configuration.md) |
| Docker сообщает, что порт занят | Проверьте порт на хосте в блоке `ports`. Если меняете его, используйте новый порт в адресе клиента. Внутри контейнера оставьте `0.0.0.0:3000`, как в примере. |
| Ошибка при подключении по HTTPS | Проверьте путь от домена до контейнера и сертификат по [руководству Traefik](./proxy.md#если-не-работает). |

## Сервер отвечает, а музыка недоступна

| Что видно | Что проверить |
| --- | --- |
| Каталог пуст | Убедитесь, что контейнер видит папку с музыкой. После копирования запустите сканирование и откройте [отчёт](./library.md#если-трек-не-появился). |
| Трек есть в каталоге, но не играет | Проверьте наличие аудиофайла по прежнему пути и поддержку его формата в клиенте. [Добавление музыки](./library.md) |
| Клиент получает `401 Unauthorized` | Проверьте адрес сервера в клиенте и войдите заново. Если отправляете запрос вручную, проверьте заголовок `Authorization`. [Пользователи и доступ](./accounts.md) |
| В браузере ошибка CORS | Укажите точный адрес страницы плеера в [настройках CORS](./proxy.md#если-веб-плеер-на-другом-домене). |
| Не работает поиск метаданных, рекомендаций или загрузок | Проверьте настройки нужного источника и сообщение задания. Пока внешний сервис недоступен, музыка из вашей библиотеки остаётся доступной. [Метаданные](./metadata.md) · [Рекомендации](./discovery.md) · [Загрузки](./downloads.md) |

## Заканчивается место на диске

Для стандартной установки проверьте размер папок и свободное место:

```sh
sudo du -sh data music
df -h data music
```

Если музыка или загрузки находятся в другой папке, подставьте путь
на хосте. Лимит одной загрузки ограничивает размер файла, а общий
размер загрузок зависит от того, сколько треков уже добавлено.
Перед удалением данных сделайте [резервную копию](./operations.md).
