# Справочник API

Все операции приложения находятся под `/api/v1/`. Этот указатель
генерируется из схемы настоящего сервера и сохраняет разделы Swagger.
Ищите по пути, методу или английскому описанию операции.

- [Скачать OpenAPI JSON](/openapi.json): схемы тел, ответы ошибок,
  типы параметров и исходник для генерации клиента.
- Включите `docs.enabled` для интерактивного Swagger по `/docs`
  и актуальной схемы инстанса по `/openapi.json`. При выключении их нет.
- Полные сценарии описаны в [руководстве клиента](../clients/overview.md).

Статическая схема соответствует стандартному **публичному каталогу**.
При `library.public_catalog = false` чтение каталога требует bearer;
актуальная схема инстанса отражает настройку. "Публичный по умолчанию"
не отменяет правила ресурсов. Личные и административные операции требуют
соответствующих учётных данных.

Названия групп и описания операций сохраняются на английском, как
в исходной OpenAPI-схеме, чтобы не создавать расходящийся перевод контракта.
